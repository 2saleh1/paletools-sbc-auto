# Paletools SBC Auto Completer

أداة خفيفة لأتمتة SBC في EA FC Web App مع Paletools.

## الموقع

https://2saleh1.github.io/paletools-sbc-auto/

## ماذا تفعل الأداة؟

- تحميل قائمة SBC تلقائيا مع بحث بالاسم.
- تشغيل SBC محدد بعدد تكرارات تختاره.
- تشغيل من التحدي المفتوح حاليا.
- تشغيل التحديات اليومية بالترتيب:
    - Daily Bronze Upgrade
    - Daily Silver Upgrade
    - Daily Common Gold Upgrade
- استخدام Smart Builder ثم Submit ثم Claim Rewards تلقائيا.

## التشغيل السريع

1. شغل Paletools في Web App.
2. شغل السكربت (bookmarklet أو console).
3. من الواجهة اختر أحد الأوضاع:
     - بدء (من القائمة)
     - بدء من التحدي المفتوح
     - تشغيل اليوميات
4. اكتب عدد التكرارات واضغط تشغيل.

## ملاحظات

- الأداة لا تفتح البكجات ولا تدير المكررات.
- استخدمها على مسؤوليتك.
- يفضل التجربة على SBC منخفض التكلفة أولاً.
