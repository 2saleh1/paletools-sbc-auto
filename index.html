Features

Auto Complete SBCs
Automatically completes SBCs using Paletools Smart Build
Pack Opening
Opens reward packs automatically after each SBC
Gold Management
Sends duplicate gold players to SBC Storage
Quick Sell
Auto quick-sells duplicate bronze and silver players
Smart Stop
Automatically stops when SBC Storage is full
Live Statistics
Real-time tracking of completed SBCs and opened packs

How It Works

Step 1: Select SBC
Choose which SBC to complete from the available list
Step 2: Smart Build
Uses Paletools Smart Build to auto-fill the squad
Step 3: Submit
Automatically submits the SBC and claims rewards
Step 4: Open Packs
Opens reward packs and manages duplicates
Step 5: Manage Duplicates
Golds to SBC Storage, Bronze/Silver quick-sold
Step 6: Repeat
Cycles through based on your configured settings

Usage Instructions

Important Requirement

Paletools must be activated first. This script depends on the Smart Build feature.

Preparation

  • Open EA FC Web App
  • Activate Paletools (required)
  • Ensure you have enough players in your club

Activate Script

  • Click the bookmark you created
  • Side panel will appear on screen

Load SBC List

  • Click "Load SBC List" button
  • Wait for the list to populate

Configure Settings

  • Select SBC from dropdown
  • Set number of cycles
  • Configure duplicate management options

Start Automation

  • Click "Start" button
  • Monitor progress in real-time
  • Can stop anytime using "Stop" button

Configuration Options

Setting Description Default
Gold to SBC Storage Send duplicate gold players to SBC Storage Enabled
Bronze/Silver Quick Sell Automatically quick-sell duplicate bronze and silver players Enabled
Stop on Storage Full Stop script when SBC Storage reaches capacity Enabled
Cycles Number of times to repeat the process 1
Advanced Configuration

Edit the CONFIG object at the top of sbc-auto-complete.js for more options like timing delays and pack counts.

Complete Workflow

1. Select SBC from list 2. Click Smart Build (Paletools) 3. Wait for squad completion 4. Submit SBC 5. Claim rewards 6. Open reward packs 7. Process duplicates: - Gold duplicates → SBC Storage - Bronze/Silver duplicates → Quick Sell - Other items → Club 8. Repeat cycle (if configured)

Important Warnings

Use at Your Own Risk
  • EA may consider this against Terms of Service
  • Always monitor script execution - do not leave unattended
  • Test on cheap SBCs first before using on expensive ones
  • Ensure SBC Storage has available space
  • Script requires Paletools to be activated

Troubleshooting

Script Not Working
  • Ensure Paletools is activated first
  • Refresh EA FC Web App
  • Verify code was copied completely
Empty List
  • Navigate to SBC section first
  • All SBCs may be completed
  • Try refreshing the list
Smart Build Fails
  • Update Paletools to latest version
  • Need more players in club
  • Try different SBC
Sudden Stop
  • SBC Storage may be full
  • Not enough players available
  • Check console for errors (F12)
